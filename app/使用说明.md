# 项目材料管理

这是一个在本机运行的项目材料管理工具。项目组分别拥有自己的流程图；每个节点可填写说明、列出文档模板名称，并保存完成情况和历次检查。材料正文继续通过原有方式管理。

## 打开工具

在苹果电脑上，双击 `启动工具.command`。在安装了 Python 3 的 Windows 电脑上，双击 `启动工具.bat`。工具会打开独立窗口；尚未安装桌面窗口组件时，会使用默认浏览器打开。

使用浏览器时，请保留启动工具的终端窗口。使用完毕后关闭终端窗口即可结束服务。程序只接受本机访问，日常使用无需连接互联网。

## 开始记录

首次打开时，可以先进入示例项目组了解操作。这个项目组的说明、连接关系和情况记录均为演示内容。

项目组直接用老师姓名作为名称。新建项目组时填写老师姓名，对接学生填在“对接学生姓名”里——学生只记录在项目资料中，卡片、标题栏和收藏夹都不显示；需要查看或修改时，点卡片右上角的“⋯”，选“编辑基本信息”。

建立正式项目组时，可以选择空白流程，也可以选择已有模板。项目组管理模板用七个上级节点组织参考清单中的32项工作，学院管理模板包含18项工作。节点说明留待填写。初始顺序按清单分类排列，可以按照实际工作的先后关系调整。

进入项目组后，默认打开“逐项检查”。左侧过程目录支持搜索，可以从任意节点开始；底部的“上一个”和“下一个”按流程顺序切换。填写本次情况并保存后，工具会为今天留下一条记录：同一天再次保存只更新当天那条，第二天再保存才会记为下一次检查。进入“历次检查”可以查看以前保存的完整内容。

切换到“流程总览”可以从左到右查看节点和箭头。点击节点进入办理页；在办理页点击流程图图标，可以返回对应位置。包含下级流程的节点可以向下展开，也可以单独进入该层级查看。

“调整顺序”可以改变同级节点的办理顺序，并连接相邻节点。“归入下级流程”可以将选中的同级节点收纳到一个上级节点中。节点设置中也可以调整所属流程及计划日期。

在节点办理页点击星号，可以将这个项目的这个过程加入收藏夹。收藏夹按文件夹、项目组两级归类，项目组名称可以点击直接进入；已归档项目组里的收藏单独列在最后。过程目录里，每个过程下方用颜色标出完成情况；涉及多份文档的过程会在行尾出现一个展开箭头，展开后按序号列出每份材料及其状态，点一下就能直接跳到办理页对应的那一段材料。

在“项目组”页可以用文件夹给项目组分类：新建、重命名或删除文件夹，新建项目组时选择“所属文件夹”。删除文件夹不会删除里面的项目组和记录，它们会回到“未分类”。

项目组卡片右上角、侧栏快捷入口右侧都有“⋯”：可以编辑基本信息、把项目组移动到别的文件夹、归档，或删除。归档后项目组从列表和快捷入口隐藏，节点与记录全部保留，点“显示已归档”还能找到并恢复。已经有情况记录的项目组不能删除，避免记录丢失；还没有记录的项目组可以直接删除。

一次采购对应一个节点。需要记录多次采购时，分别建立节点，每个节点保留自己的材料情况与历史。

## 生成通知

侧栏的“生成通知”可以按流程模板生成通知文字。选择流程模板后，在左侧勾选需要通知的节点或材料，可以同时勾选多个节点、多份材料（勾节点名会选中它下面的全部材料）。工具会按“各学院，现将本年度质量工作布置如下”的格式列出材料清单：只选一个节点时写作“二、某节点本阶段需编制的材料清单”，选了多个节点时按节点分组列出。提交时间留成空位，直接在文本框里填写即可。改好以后点“复制通知”，粘贴到微信或邮件发送。

通知只生成文字，不会写入项目组，也不会产生记录。

## 导出 Excel 表格

项目组中的导出功能会生成一个 Excel 工作簿，包含“节点完成情况”“文档完成情况”和“节点说明”三张表。

前两张表都按“检查日期 × 节点/材料”排列：一行是一天（一次检查），一列是一个节点（表 1）或一份材料（表 2）。单元格里是那天检查到的状态和修改意见；同一天检查了多个节点，也合并成同一行。空白表示那天没有检查到这一项，表底有一行说明。

“节点完成情况”的节点名下面多一行“对应模板”，列出这个节点配置的文档模板名称，方便对照要交哪几份材料。

“节点说明”表按附件 10 的形式平铺：一行一个节点，顺序和流程一致，列出序号、节点名称、节点说明和对应模板，不再按父子层级展开。节点说明就是“编辑节点说明与模板”里填写的那段文字。

日期从新到旧排列。表头和前两列（检查日期、记录人）是冻结的，文档完成情况表只冻结检查日期一列，节点说明表只冻结节点路径一列，左右拖动时始终能看到是哪一天、哪一个节点。日期和节点名较长时可以把列拖宽。同一天后来又补充了检查，重新导出即可，那一行会更新为当天最后的内容。

交付前需在目标 Windows 电脑上完成断网启动、保存记录、关闭后重新打开、读取历史、备份恢复和更新程序后的数据保留检查。
