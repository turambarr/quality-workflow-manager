# 项目材料管理

这是一个在本机运行的项目材料管理工具。项目组分别拥有自己的流程图；每个节点可填写说明、列出文档模板名称，并保存完成情况和历次记录。材料正文继续通过原有方式管理。

## 打开工具

在苹果电脑上，双击 `启动工具.command`。在安装了 Python 3 的 Windows 电脑上，双击 `启动工具.bat`。工具会打开独立窗口；尚未安装桌面窗口组件时，会使用默认浏览器打开。

使用浏览器时，请保留启动工具的终端窗口。使用完毕后关闭终端窗口即可结束服务。程序只接受本机访问，日常使用无需连接互联网。

## 开始记录

首次打开时，可以先进入“示例项目组”了解操作。这个项目组的名称、说明、连接关系和情况记录均为演示内容。

建立正式项目组时，可以选择空白流程，也可以选择已有模板。项目组管理模板用七个上级节点组织参考清单中的32项工作，学院管理模板包含18项工作。节点说明留待填写。初始顺序按清单分类排列，可以按照实际工作的先后关系调整。

进入项目组后，默认打开“逐项检查”。左侧过程目录支持搜索，可以从任意节点开始；底部的“上一个”和“下一个”按流程顺序切换。填写本次情况并保存后，工具新增一份记录。进入“历次记录”可以查看以前保存的完整内容。

切换到“流程总览”可以从左到右查看节点和箭头。点击节点进入办理页；在办理页点击流程图图标，可以返回对应位置。包含下级流程的节点可以向下展开，也可以单独进入该层级查看。

“调整顺序”可以改变同级节点的办理顺序，并连接相邻节点。“归入下级流程”可以将选中的同级节点收纳到一个上级节点中。节点设置中也可以调整所属流程及计划日期。

在节点办理页点击星号，可以将这个项目的这个过程加入收藏夹。过程库汇集各套模板中的工作事项，支持搜索过程和模板名称，并将选中的过程加入项目组。

一次采购对应一个节点。需要记录多次采购时，分别建立节点，每个节点保留自己的材料情况与历史。

## 导出 Excel 表格

项目组中的导出功能会生成一个 Excel 工作簿，包含“节点情况汇总”和“文档明细”两张工作表。

节点情况汇总采用横向排列：每个工作节点占一列，上方显示流程路径和对应模板名称，下方显示最近一次保存的完成情况、修改意见、记录人和记录时间。父节点下的工作按层级顺序排列，已归档节点不参与导出。前三列和前三行保持固定，便于查看较宽的表格。

文档明细按每份材料分别列出状态和修改意见，同时保留节点说明、本次情况、记录人、记录时间与版本。节点尚未设置文档模板时，也会保留一行。最新记录中使用的模板名称保持原样，后续新增且尚未记录的模板显示“尚未记录”。

导出结果汇总各节点最近一次保存的情况。各节点的记录时间可能不同，请结合记录时间和版本查看。汇总单元格内容较长时，可到文档明细中查看完整内容。

## 保存数据

工具将数据保存在独立的用户数据目录，程序文件更新后仍可继续使用。苹果电脑的默认目录位于用户资源库的 Application Support（应用支持）中；Windows 的默认目录位于当前用户的 LOCALAPPDATA（本地应用数据目录）中。数据备份文件应与程序文件分别保管。

预设提供项目组管理与学院管理两套流程，可按实际工作调整。尚未配置文档模板名称的工作事项，保留空列表供补充。

## Windows 桌面交付

Windows 版本由 `build_windows.ps1` 生成。打包前需要安装 Python 3；脚本会安装 pywebview（网页桌面窗口组件）和 PyInstaller（应用打包工具），然后将界面文件与 Python 程序一起打包。安装开发组件需要网络，或提前准备相应的离线安装文件。

生成结果位于 `dist/质量节点` 文件夹中。交付时复制整个文件夹，双击其中的 `质量节点.exe` 即可打开。运行电脑无需单独安装 Python。

桌面窗口使用 Windows 的 WebView2（网页显示运行组件）。离线电脑应提前安装该组件，安装文件可以从微软官方渠道准备。

交付前需在目标 Windows 电脑上完成断网启动、保存记录、关闭后重新打开、读取历史、备份恢复和更新程序后的数据保留检查。
